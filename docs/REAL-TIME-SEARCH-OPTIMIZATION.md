# 联网检索与生成优化记录

完成日期：2026-08-18

## 1. 优化目标与基线问题

本轮针对「生成结果时效性不足」与「外部服务配置体验」两个方向进行优化：

- 大纲与文稿生成完全依赖大模型训练时固化的知识，存在知识截止时间，无法获取实时/最新数据。
- 对新闻、行情、数据、最新动态等时效性内容，会生成过时甚至编造的内容。
- 生成结果缺少可核对的参考来源。
- 大模型已有「测试连接」，但 TTS 与联网搜索缺少等价的可视化验证手段。
- TTS 模型与音色只能手动输入，无法从服务端动态获取可选列表。

## 2. 分步优化处理及效果

### 步骤 1：新增联网检索模块

处理：

- 新增 `lib/search.ts`，统一支持 Tavily / Serper / Bocha（博查）三家搜索服务商。
- 结果统一归一化为 `SearchResult`（标题、URL、摘要、正文）。
- 针对主题自动构造 2 条查询：主题本身 + “最新进展 / 关键数据 {年份}”。
- 结果按 URL 去重、正文截断，拼接为不超过 3200 字符的研究上下文。
- 进程内 10 分钟缓存，按“主题 + 小时”复用，避免短时间重复扣费。
- 未开启、未配置 Key、或检索全部失败时返回 `null`，调用方静默降级为纯大模型生成。

效果：生成链路从“闭卷”变为“可检索最新资料”，且任何检索故障都不会阻断生成流程。

验证：Bocha 实测返回最新新闻（如 DeepSeek IPO 筹备），HTTP 200；网络探测明确区分了各服务商可达/不可达。

### 步骤 2：提示词注入检索上下文与时间锚点

处理：

- `outlineSystemPrompt` / `scriptSystemPrompt` 注入“今天是 {日期}”。
- `outlineUserPrompt` / `scriptUserPrompt` 增加 `research` 参数，拼接检索资料块。
- 明确要求：优先采用检索资料中的事实与数据，资料不足或矛盾时保守处理，禁止编造具体数字。
- 四个生成路由（大纲、文稿、大纲单场景、文稿单场景）在生成前检索并注入上下文。

效果：文稿优先基于最新事实撰写，并在旁白或画面要点中自然引用关键数据。

验证：TypeScript 严格检查通过。

### 步骤 3：需求级「联网搜索」开关（默认开启）

处理：

- `Requirements` 新增 `enableSearch`（可选字段，未设置视为开启）。
- 首页创建表单与需求步骤均提供 Switch，默认开启。
- `DEFAULT_REQUIREMENTS` 设为 `true`，`getProject` 读取时补齐默认值。

效果：用户可自主控制是否联网检索；旧项目无需手工迁移即可获得默认开启行为。

验证：旧项目 JSON 加载时自动补齐 `enableSearch`，无需迁移脚本。

### 步骤 4：参考来源展示与持久化

处理：

- 新增 `SourceRef` 类型与 `Project.sources` 字段。
- 检索结果回存项目，并在「大纲」「文稿」步骤用 `SourceList` 组件展示可点击来源链接。

效果：用户可以回看并核对文稿的事实来源。

验证：生成后来源列表在页面顶部正常展示，链接可点击跳转。

### 步骤 5：服务连接测试（LLM / TTS / 搜索）

处理：

- 新增 `testSearchConnection`（`lib/search.ts`）与 `testTtsConnection`（`lib/tts.ts`）。
- 新增 `/api/config/search-test`、`/api/config/tts-test` 两个接口。
- 设置页为「联网搜索」「TTS」增加「测试连接」按钮与结果提示。
- TTS 测试成功时返回测试音频，前端直接渲染 `<audio>` 播放器供试听。

效果：三个外部服务（LLM / TTS / 搜索）均可一键验证连通性，配置错误可即时定位。

验证：TTS 测试返回 `audio/mpeg`，浏览器可播放。

### 步骤 6：TTS 模型与音色下拉选择

处理：

- 新增 `listTtsOptions`，调用远端 `/v1/models` 动态解析“基础模型”与“音色”。
- 音色从 `tts-1-<voice>` 形式的模型 ID 中提取；解析失败回退标准 OpenAI 默认列表。
- 新增 `/api/config/tts-models` 接口。
- 设置页 TTS 模型/音色由文本输入改为 `NativeSelect` 下拉，并增加「刷新模型/音色列表」按钮。
- 当前已配置但不在列表中的值会临时保留为可选项，避免丢值。

效果：无需手动输入，支持任意 OpenAI `audio/speech` 兼容服务的动态模型/音色列表。

验证：自定义 TTS 服务返回的 15 个模型被正确解析为 2 个基础模型 + 13 个音色。
